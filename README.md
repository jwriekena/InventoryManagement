# Inventory Management Project
WGU D482 Basic Java Inventory Managment Application

  This is my project from WGU C482 - Software I in 2024.
  It is a simple Java Application for managing a simple inventory based on the very specific rubric requirements.  A requirement was to generate an accompanying JavaDoc.
  The IDE used was IntelliJ IDEA.  The language used was Java.  The JavaDocs were created using IDEA's built in functionality.
